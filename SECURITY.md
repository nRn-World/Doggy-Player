# Security Policy

## Supported Versions

Doggy Player is distributed as a desktop application and ships security fixes
through its built-in auto-updater. Only the latest released line is supported.

| Version        | Supported          |
| -------------- | ------------------ |
| 1.1.x (latest) | :white_check_mark: |
| < 1.1          | :x:                |

Please make sure you are running the newest release (currently **1.1.75**) before
reporting anything — Doggy Player updates itself automatically, but a build kept
open for a very long time may still be behind. You can always download the
current installer from the [Releases](https://github.com/nRn-World/Doggy-Player/releases/latest)
page.

## Reporting a Vulnerability

If you discover a security vulnerability within Doggy Player, please send an
e-mail to **bynrnworld@gmail.com**.

We ask that you **do not** report security vulnerabilities through public GitHub
issues, discussions, or pull requests — and please do not demonstrate the issue
publicly before it has been fixed.

A useful report includes:

* The Doggy Player version (`Help` → about, or the installer version) and your OS.
* A clear description of the issue and its impact.
* Step-by-step instructions to reproduce it.
* Any proof-of-concept files, logs, or screenshots (please share them privately).

### What to expect

* You will receive an acknowledgment of your report within **48 hours**.
* We will keep you updated on the progress of the fix.
* Once fixed, we will release a new version — published to
  [Releases](https://github.com/nRn-World/Doggy-Player/releases) and delivered to
  installed apps by the built-in updater — and credit you for the discovery
  (if you would like to be credited).
* Please give us reasonable time to release a fix before disclosing the issue
  publicly.

Thank you for helping keep Doggy Player and its users safe. 🐶
